# 0001 — Concept: alife city cultural ecosystem

- **Status:** Accepted (2026-10-09)
- **Decision:** Build a god-game sandbox in which taste-genome agents and venue agents form an ecology over a real city map. The simulation's rules follow Qloo affinity edges, and the baseline is calibrated against Qloo heatmaps. The Claude co-pilot shares the toolbar's action layer.
- **Alternatives considered:** pure event-propagation simulation; a taste-space petri dish; an LLM agent society; non-sim products (Taste Translator, Reminiscence companion, Show Doctor, Synthetic focus group).
- **Rationale:** strongly differentiated, and the artificial-life idea is what the user wants to explore. Deriving the dynamics from Qloo answers the "would it work without Qloo?" test. The venue/scene-planning pitch covers Potential Impact (and suits the Live Nation judge).
