# City geometry

Files in this folder are derived from OpenStreetMap data and are licensed under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

© OpenStreetMap contributors — https://www.openstreetmap.org/copyright

They are generated by `pnpm build:geo <city>`, which simplifies and clips roads, water and parks,
then reprojects them to local metres. The application code in this repository is MIT-licensed; this
data is not.

`<city>-street-names.json` contains named OSM road pieces for labels in older prebuilt worlds.
Refresh all three supplements with `npx tsx scripts/build-street-names.ts` (one combined Overpass
request; avoid repeated runs). Each supplement records its projection origin, fetch date and
attribution. Labels match nearby aligned streets in the existing geometry; these files do not
replace roads, venue locations or Qloo data.
